# 📌 Project Overview

This is a modern **Developer Portfolio Website** built using **Next.js App Router**.

The portfolio showcases:
- Featured projects
- Full stack applications
- Skills & technologies
- Project details pages
- Responsive modern UI
- Dynamic project data from backend API

- 🚀 Modern Portfolio Design
- 📱 Fully Responsive Layout

# 🚀 How to Run This Project

```bash
# Clone repo
git clone https://github.com/abdul-korim-web/portfolio

# Open folder
cd portfolio

# Install dependencies
npm install

# Run project
npm run dev
```

# 🌐 Open in Browser

```bash
http://localhost:3000
```
